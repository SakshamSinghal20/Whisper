        Connection & scanning guide
        

          

            
Connect Bitcoin Core

            

              Set BITCOIN_RPC_URL, BITCOIN_RPC_USER,
              and BITCOIN_RPC_PASS in .env. Match
              NETWORK to your node, then restart Whisper.
            

            

              Use an unpruned Bitcoin Core 26+ node for historical scanning.
              Whisper catches up over RPC; ZMQ can wake the indexer sooner.
            

          

          

            
Read coverage before scanning

            

              Request a range within the indexed coverage. An incomplete range
              returns 409, so an empty result never stands in for
              missing blocks.
            

            

              Keep private keys in the Python client. The index supplies public
              transaction data; it does not prove confirmations or amounts.
